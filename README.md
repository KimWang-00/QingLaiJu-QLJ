# 轻来剧 (QingLaiJu - QLJ)

AI 短剧制作工作台 — 从剧本到成片的一站式 AI 创作平台

![版本](https://img.shields.io/badge/version-2.0.0-blue)
![Python](https://img.shields.io/badge/python-3.10+-yellow)

## 简介

轻来剧是一款面向短视频创作者的 AI 短剧制作工具，集成了剧本生成、分镜管理、资产库、无限画布、3D 预演、视频剪辑等全流程功能，让短剧创作变得简单高效。

## 核心功能

| 模块 | 功能描述 |
|------|----------|
| 📖 剧本工坊 | AI 生成剧本，支持题材/风格选择、分集管理 |
| 🎞️ 分镜中心 | 自动拆分镜头，支持镜头描述、机位、时长编辑 |
| 🎭 资产库 | 管理角色、场景、道具等素材资产 |
| 🧩 无限画布 | 节点式 AI 生图/生视频工作流编排 |
| 🧊 3D 预演台 | 3D 场景预览，机位设置、物件摆放 |
| 🪄 文本转3D | 文本描述生成 3D 模型 |
| 🎬 剪辑导演台 | 视频剪辑、拼接、导出 |
| 📼 生成视频库 | 管理所有 AI 生成的视频片段 |

## 技术栈

- **后端**: FastAPI + Python 3.10+
- **前端**: Vue 3 + Vite + Pinia
- **UI**: 液态玻璃设计 (Glass Morphism)
- **渲染**: PIL + numpy 软件渲染（3D 预演）
- **打包**: PyInstaller + Inno Setup
